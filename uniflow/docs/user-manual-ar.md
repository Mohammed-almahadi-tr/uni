# دليل استخدام نظام جامعة امدرمان الاهلية

الإصدار: 2.0  
النظام: UniFlow  
لغة الواجهة المقصودة في هذا الدليل: العربية

## 1. عناوين الدخول

| المستخدم | العنوان المحلي |
| --- | --- |
| الموقع العام | `http://localhost:3000/ar` |
| دخول الموظفين | `http://localhost:3000/ar/login` |
| بوابة مرشح الوزارة | `http://localhost:3000/ar/candidate/profile` |
| بوابة الطالب وولي الأمر | `http://localhost:3000/ar/portal/login` |
| استيراد كشف الوزارة | `http://localhost:3000/ar/console/registry/ministry-import` |
| قرارات المسجل | `http://localhost:3000/ar/console/registry/candidate-interviews` |

في الخادم المنشور استبدل `http://localhost:3000` باسم نطاق الجامعة.

## 2. قواعد عامة

1. يدخل كل موظف بحسابه الشخصي، ولا يجوز مشاركة كلمات المرور.
2. لا تظهر للموظف إلا القوائم التي تسمح بها صلاحيات دوره.
3. ظهور رسالة خضراء يعني نجاح العملية، والرسالة الحمراء تعني وجود خطأ يجب تصحيحه.
4. العمليات المالية المعتمدة لا تُحذف؛ التصحيح يتم بالإلغاء أو القيد العكسي.
5. بعض العمليات تحتاج موظفاً ثانياً للمراجعة أو الاعتماد.
6. استخدم زر **تسجيل الخروج** عند العمل من جهاز مشترك.

## 3. مسار القبول المعتمد

لا يوجد تقديم ذاتي للكليات. الطالب لا يختار الكلية ولا ينشئ طلب قبول بنفسه.

المسار هو:

1. تستلم الجامعة كشف المرشحين من وزارة التعليم العالي بصيغة Excel.
2. يرفع موظف مخول الكشف في النظام.
3. ينشئ النظام سجلات مرشحين فقط، ولا ينشئ طلاباً أو حسابات طلابية.
4. يصدر موظف القبول رمزاً لمرة واحدة لكل مرشح.
5. يدخل المرشح إلى بوابة مرشح الوزارة ويكمل بياناته.
6. يظهر المرشح للمسجل بعد إكمال البيانات.
7. يحدد المسجل البرنامج ويقرر القبول أو الرفض.
8. ينتقل المقبول إلى حالة **بانتظار التسجيل**.
9. بعد إكمال إجراءات التسجيل يصبح طالباً، ثم يمكن إصدار دعوة لبوابة الطالب.

فتح `/ar/apply` أو `/ar/apply/status` يحول المستخدم تلقائياً إلى بوابة مرشح الوزارة.

## 4. رفع كشف الوزارة خطوة بخطوة

الدور المسؤول: **المسجل** أو أي موظف لديه صلاحية `admission.import`.

1. سجل الدخول من `/ar/login`.
2. من القائمة افتح **السجل**.
3. اختر **استيراد قوائم الوزارة**.
4. اضغط اختيار الملف وحدد ملفاً بامتداد `.xlsx`.
5. يجب ألا يتجاوز حجم الملف 4 ميغابايت.
6. اضغط **التحقق من القائمة واستيرادها**.
7. إذا ظهرت أخطاء، صحح الصفوف المذكورة ثم أعد رفع الملف.
8. عند النجاح تظهر أسماء المرشحين أسفل نموذج الرفع.

### أعمدة ملف Excel المطلوبة

يجب أن يكون الصف الأول عناوين الأعمدة التالية:

| العمود | مثال |
| --- | --- |
| `الاسم الرباعي` | محمد أحمد علي حسن |
| `المدرسة` | مدرسة امدرمان الثانوية |
| `الرقم الوطني` | 12345678901 |
| `سنة القبول` | 2026 |
| `الدفعة` | B26 |

شروط الملف:

- يحتوي الملف على دفعة واحدة فقط.
- رمز الدفعة يجب أن يطابق دفعة نشطة معرفة مسبقاً في النظام.
- سنة القبول يجب أن تطابق سنة الدفعة.
- الرقم الوطني لا يتكرر داخل الملف أو في كشف سبق استيراده.
- لا تكرر عناوين الأعمدة ولا تستخدم عنوانين بديلين للحقل نفسه.
- لا يؤدي الاستيراد إلى إنشاء طالب أو منحه صلاحية دخول بوابة الطلاب.

## 5. إصدار رمز بوابة المرشح

الدور المسؤول: **المسجل**، ويحتاج صلاحية `admission.manage`.

1. افتح **السجل → استيراد قوائم الوزارة**.
2. ابحث عن المرشح في قائمة المرشحين المستوردين.
3. اضغط **إصدار رمز الملف الشخصي**.
4. انسخ الرمز الظاهر وأرسله للمرشح عبر وسيلة اتصال معتمدة.
5. أخبر المرشح أن الرمز صالح لمدة 14 يوماً ولمرة واحدة.

إصدار رمز جديد يلغي أي رمز سابق لم يُستخدم.

## 6. تعليمات مرشح الوزارة

1. افتح `/ar/candidate/profile`.
2. أدخل رمز المرشح الصادر من الجامعة.
3. اضغط **متابعة**.
4. تأكد أن الاسم العربي والرقم الوطني الظاهرين يخصانك.
5. أدخل الاسم الرباعي باللغة الإنجليزية.
6. أدخل اسم ولي الأمر والبريد الإلكتروني ورقم الهاتف.
7. اضغط **إرسال البيانات**.

لا تعرض البوابة اختيار كلية أو برنامج. يحدد المسجل البرنامج بعد استلام البيانات.
ولا يعطي رمز المرشح صلاحية الاطلاع على الرسوم أو التسجيلات أو بيانات أي طالب.

## 7. قرار المسجل

الدور المسؤول: **المسجل**، ويحتاج صلاحية `admission.manage`.

1. افتح **السجل → قرارات المسجل**.
2. ابحث باسم المرشح أو رقمه الوطني.
3. افتح المرشح الذي حالته **اكتمل الملف — بانتظار المسجل**.
4. اختر الكلية والبرنامج المناسبين من قائمة البرامج النشطة.
5. اختر **قبول** أو **رفض**.
6. عند الرفض اكتب السبب في خانة الملاحظات.
7. اضغط **تسجيل قرار المسجل**.

المقبول ينتقل إلى **بانتظار التسجيل**، والمرفوض ينتقل إلى **مرفوض**. لا يستطيع
المرشح تعديل قرار المسجل أو اختيار برنامج آخر بنفسه.

## 8. دور مدير الجامعة

الدور الافتراضي: **مدير الجامعة**.

### إدارة الموظفين

1. افتح **الإعدادات → المستخدمون**.
2. أضف اسم الموظف وبريده وبيانات الدخول المطلوبة.
3. امنحه الدور المناسب فقط.
4. عطّل الحساب عند انتهاء خدمة الموظف بدلاً من مشاركته أو حذفه عشوائياً.

### إدارة الأدوار والصلاحيات

1. افتح **الإعدادات → الأدوار**.
2. أنشئ اسماً عربياً وإنجليزياً للدور.
3. حدد أقل مجموعة صلاحيات يحتاجها العمل.
4. احفظ الدور.

يرفض النظام جمع صلاحيات متعارضة، مثل إعداد السند واعتماده بواسطة الشخص نفسه.

### تغيير اسم الجامعة والهوية

1. افتح **الإعدادات → الهوية**.
2. راجع الرمز المختصر `OAU` والألوان والشعار والعبارة التعريفية.
3. احفظ التعديلات.
4. راجع الموقع بالعربية والإنجليزية.

### إدارة الموقع

من **الإعدادات → محتوى الموقع** يمكن تعديل الصفحة الرئيسية والأخبار والتقويم،
ثم نشر المحتوى لمن لديه صلاحية `cms.publish`.

### سجل التدقيق

افتح **الإعدادات → سجل التدقيق** للبحث حسب التاريخ أو الموظف أو العملية. استخدم
فحص السلسلة للتأكد من سلامة سجل التدقيق.

## 9. دور المسجل

الدور الافتراضي: **المسجل**.

المهام الأساسية:

- رفع كشف الوزارة وإصدار رموز المرشحين.
- تحديد برنامج المرشح وتسجيل القبول أو الرفض.
- البحث عن الطلاب وفتح ملفاتهم.
- توثيق مستندات الطالب أو رفضها مع ذكر السبب.
- تسجيل الطالب للفصل الدراسي وإلغاء التسجيل عند وجود صلاحية.
- وضع الإيقافات ورفعها وفق قواعد الفصل بين المسؤوليات.
- تغيير حالة الطالب أو تحويله بين البرامج.
- إدارة الجهات الراعية والمنح المقترحة.
- تشغيل تقارير الطلاب والتسجيل.

### تسجيل طالب لفصل دراسي

1. افتح **السجل → مكتب التسجيل**.
2. ابحث عن الطالب بالاسم أو الرقم الجامعي أو الرقم الوطني.
3. اختر الفصل والسنة الدراسية وتاريخ التسجيل.
4. اختر البنود الاختيارية والخصم المسموح إن وجد.
5. اضغط التسعير وراجع الرسوم والخصم والصافي.
6. اعتمد التسجيل.

إذا تجاوز الخصم الحد المسموح يبقى التسجيل بانتظار اعتماد موظف مالي مستقل.

### الإيقافات والحالة

- من **السجل → الإيقافات** ضع إيقافاً مالياً أو أكاديمياً أو مستندياً مع السبب.
- من **السجل → الحالة والتحويل والانسحاب** نفّذ التأجيل أو الانسحاب أو التحويل.
- اقرأ الأثر المالي المعروض قبل تأكيد أي تغيير.

## 10. دور الطبيب

الدور الافتراضي: **الطبيب**.

1. افتح **السجل → السجلات الطبية** للطلاب المسجلين.
2. ابحث عن الطالب وافتحه.
3. أدخل تاريخ الفحص واسم الطبيب وفصيلة الدم والنتائج.
4. اختر لائق أو لائق بشروط أو غير لائق.
5. اكتب السبب عند وجود شرط أو عدم لياقة.
6. احفظ الفحص.

السجل الطبي الجديد يستبدل السجل الحالي مع الاحتفاظ بالتاريخ؛ لا تعدل نتيجة قديمة.
لا يحق لغير الموظف الطبي الاطلاع على المعلومات الطبية الحساسة.

## 11. دور أمين الصندوق

الدور الافتراضي: **أمين الصندوق**.

### استلام رسوم طالب

1. افتح **المالية → مكتب الصندوق**.
2. ابحث عن الطالب وتأكد من اسمه ورقمه.
3. راجع الرصيد والرسوم المستحقة.
4. اختر طريقة الدفع: نقد، تحويل بنكي، شيك أو بوابة دفع.
5. أدخل المبلغ والتاريخ والمرجع.
6. راجع توزيع الدفعة ثم أكد الإيصال.
7. اطبع الإيصال أو سجل رقمه.

لا يمكن استلام نقد قبل ربط أمين الصندوق بخزنة مناسبة.

## 12. دور مشرف الصندوق

الدور الافتراضي: **مشرف الصندوق**.

- يراجع الإيصالات.
- يلغي إيصال اليوم عند وجود سبب صحيح وصلاحية `receipt.cancel`.
- يدير مراحل الشيك: مستلم، أرسل للبنك، تم التحصيل أو مرتجع.
- يعيد الشيك غير المقدم لصاحبه عند الحاجة.
- يصدر فواتير الجهات الراعية ويسجل تحصيلها.

الإلغاء لا يحذف الإيصال أو أثره من سجل التدقيق.

## 13. دور المحاسب الأول

الدور الافتراضي: **محاسب أول**.

### سندات القيد

1. افتح **المالية → سندات القيد**.
2. أنشئ مسودة السند وأدخل التاريخ والبيان.
3. أضف حسابات المستوى الخامس فقط.
4. أدخل المدين والدائن وتأكد من تساويهما.
5. أرسل السند للمراجعة.

لا يجوز للمعد مراجعة أو اعتماد سند أنشأه بنفسه.

### مهام أخرى

- إدارة دليل الحسابات ومراكز التكلفة.
- إعداد المدفوعات دون اعتمادها بنفسه.
- إدارة الشيكات.
- إعداد الميزانية وإصداراتها.
- تسجيل فواتير الموردين.
- إدارة الأصول وتشغيل الإهلاك.
- إدارة مصفوفة الرسوم دون اعتماد نسخته بنفسه.

## 14. دور المراجع المالي

الدور الافتراضي: **المراجع المالي**.

1. افتح **المالية → الاعتمادات**.
2. راجع مستند السند وتاريخه وحساباته ومرفقاته.
3. تحقق من تساوي المدين والدائن وصحة الفترة.
4. وافق للمستوى التالي أو ارفض مع كتابة السبب.
5. استخدم التقارير المالية وسجل التدقيق لإجراء المطابقات.

## 15. دور المدير المالي

الدور الافتراضي: **المدير المالي**.

- الاعتماد النهائي وترحيل السندات.
- عكس السندات والرسوم المعتمدة مع سبب واضح.
- فتح وإغلاق الفترات المالية.
- اعتماد الميزانيات والخصومات الكبيرة.
- اعتماد أوامر الشراء والمدفوعات وتغيير حسابات الموردين.
- اعتماد مصفوفة الرسوم والمنح وعقود الرعاية.
- مراجعة القوائم والتقارير المالية.

الأصل المالي المرحّل لا يُحذف؛ استخدم القيد العكسي.

## 16. دور العميد

الدور الافتراضي: **العميد**.

- الاطلاع على الهيكل الأكاديمي والطلاب والتسجيلات.
- مراجعة بيانات القبول والطاقة الاستيعابية.
- تشغيل تقارير الطلاب.
- استخدام تجاوز الطاقة فقط عند وجود مبرر وصلاحية `admission.override`.

## 17. دور مسؤول المشتريات

الدور الافتراضي: **مسؤول المشتريات**.

### الموردون

1. افتح **المشتريات → الموردون**.
2. أضف بيانات المورد والرقم الضريبي وشروط الدفع.
3. اقترح تغيير الحساب البنكي عند الحاجة.
4. ينتظر تغيير الحساب اعتماد موظف مستقل.

### أوامر الشراء

1. افتح **المشتريات → أوامر الشراء**.
2. اختر المورد ومركز التكلفة وأدخل البنود والكميات والتواريخ.
3. احفظ وأرسل الأمر للاعتماد.
4. لا يعتبر الأمر مصروفاً فعلياً قبل الاستلام والفاتورة.

## 18. دور أمين المخازن

الدور الافتراضي: **أمين المخازن**.

1. افتح **المشتريات → استلام البضاعة**.
2. اختر أمر شراء معتمداً.
3. أدخل الكميات التي وصلت فعلياً وتاريخ الاستلام.
4. أكد الاستلام.

لا يؤكد أمين المخازن ما لم يصل فعلياً، ولا يعتمد أمر الشراء أو استثناء الفاتورة.

## 19. الفواتير والمدفوعات والأصول

### فاتورة مورد

1. افتح **المشتريات → فواتير الموردين**.
2. اختر المورد وأمر الشراء ومحضر الاستلام.
3. أدخل رقم الفاتورة وتواريخها وبنودها.
4. راجع المطابقة الثلاثية.
5. إذا تجاوز الفرق الحد، يحيل النظام الفاتورة لاعتماد مستقل.

### دفع مورد

1. افتح **المالية → المدفوعات**.
2. يعد موظف مخول الدفع.
3. يراجعه ويعتمده موظف آخر لديه `payment.approve`.

### الأصول الثابتة

من **المشتريات → الأصول الثابتة** يمكن تسجيل الأصل وتشغيل الإهلاك الدوري أو
التصرف فيه حسب الصلاحيات. إعادة تشغيل إهلاك الفترة المكتملة لا ترحل القيد مرتين.

## 20. التقارير

الدور المطلوب: صلاحية `report.financial` أو `report.student`.

من قائمة **التقارير** يمكن تشغيل:

- ميزان المراجعة.
- القوائم المالية.
- أعمار الذمم.
- مطابقة الدفاتر المساعدة مع حسابات المراقبة.
- كشف حساب طالب.
- تقرير الخصومات.

حدد الفترة أو الطالب أو المرشحات المطلوبة، ثم شغّل التقرير وراجعه قبل التصدير.
استخدم CSV أو Excel أو الطباعة عندما يظهر الخيار.

## 21. بوابة الطالب وولي الأمر

هذه البوابة للطلاب المسجلين فقط، وليست بوابة قبول.

### تفعيل الحساب

1. يصدر المسجل دعوة من ملف الطالب.
2. يفتح الطالب أو ولي الأمر `/ar/portal/activate`.
3. يدخل رمز الدعوة وينشئ كلمة المرور.
4. بعد التفعيل يدخل من `/ar/portal/login`.

### الخدمات المتاحة

- الملخص والحالة والإيقافات.
- الحساب والرصيد والمبالغ المستحقة.
- كشف الحساب والحركات.
- الأقساط ومواعيدها.
- التسجيلات وبطاقات التسجيل.
- حالة المستندات.
- تغيير كلمة المرور وتسجيل الخروج.

ولي الأمر المرتبط بأكثر من طالب يستخدم محدد الطالب في أعلى البوابة.

## 22. حل المشكلات

| المشكلة | الحل |
| --- | --- |
| لا تظهر قائمة في واجهة الموظف | اطلب من مدير النظام مراجعة صلاحيات دورك. |
| ملف الوزارة مرفوض | تأكد من `.xlsx`، الحجم، أسماء الأعمدة، الدفعة، السنة وعدم تكرار الرقم الوطني. |
| رمز المرشح لا يعمل | راجع جميع محارف الرمز؛ قد يكون مستخدماً أو منتهياً أو أُلغي بإصدار رمز جديد. |
| المرشح لا يظهر للمسجل | يجب أن يكمل المرشح بياناته ويرسل النموذج بنجاح. |
| لا يمكن رفض المرشح | اكتب سبب الرفض في الملاحظات. |
| الطالب لا يسجل | راجع الإيقافات والمستندات والحالة ومصفوفة الرسوم والفترة الأكاديمية. |
| لا يمكن استلام دفعة | تحقق من خزنة أمين الصندوق والفترة المالية وطريقة الدفع. |
| السند لا يُرسل | تأكد من توازن المدين والدائن واستخدام حسابات قابلة للترحيل. |
| لا يمكن الاعتماد | لا يجوز لصاحب العملية اعتماد عمليته، وقد يلزم تحقق متعدد العوامل. |
| الصفحة تعرض «غير مصرح» | الحساب لا يحمل الصلاحية المطلوبة؛ لا تستخدم حساب موظف آخر. |
